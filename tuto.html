1

Se connecter

À l'ouverture, l'écran propose deux profils :

  • 👤 Usager — pour créer et suivre les demandes de votre site.
  • 🛡️ TeamGarantie — pour valider les demandes et consulter l'historique de tous les sites.

En tant qu'usager

  1. Cliquez sur Usager.
  2. Sélectionnez votre site (Audi, SEAT, SKODA ou VW).
  3. Saisissez votre e-mail @geauto.fr et votre mot de passe, puis Se connecter.
Le KVPS et le nom du site se remplissent automatiquement selon le site choisi. Vous n'avez rien à ressaisir.

En tant que TeamGarantie

  1. Cliquez sur TeamGarantie.
  2. Connectez-vous avec votre e-mail TeamGarantie et votre mot de passe.
L'accès TeamGarantie est réservé aux comptes autorisés. Un compte usager standard ne peut pas y entrer ; pour être ajouté, contactez teamgarantie@geauto.fr.

Mot de passe oublié ? Utilisez le lien 🔑 Mot de passe oublié ? : un e-mail de réinitialisation vous est envoyé.

2

Créer une demande KULANZ

Une fois connecté, l'onglet 📝 Formulaire est actif et le type Demande KULANZ est sélectionné par défaut.

① Identification du véhicule

  • Numéro de châssis — 17 caractères. Il est contrôlé en direct (les lettres I, O, Q sont interdites). Un ✔ vert confirme un châssis valide.
  • Kilométrage et N° d'OR (6 chiffres).
  • Date de l'OR, nom du demandeur et votre e-mail de suivi.
Si un véhicule a déjà fait l'objet d'une demande, commencez à taper le châssis : une suggestion apparaît et pré-remplit kilométrage, date, demandeur, e-mail…

② Nature du dommage

  • Plainte du client — décrivez le symptôme signalé.
  • Catégorie — choisissez un domaine (Motopropulseur, Transmission, Trains roulants, Carrosserie, Chauffage/Clim, Équip. électrique) ou « Saisie libre ».
  • Rubrique → Désignation → Code dommage → Code avarie — voir la section suivante.

③ Vérifications KULANZ

Les questions s'adaptent automatiquement à la marque du site (VW, Audi, SEAT, SKODA). Répondez par Oui / Non. Si une réponse rend le dossier non éligible (NOK), une alerte rouge explique pourquoi et rappelle la règle constructeur correspondante.

Exemples de blocages : code tuning présent dans SAGA, pièce d'usure, ou préconisations d'entretien non respectées.
3

Choisir les codes (cascade)

Les quatre champs fonctionnent en cascade : chaque choix affine le suivant.

  1. Rubrique — filtrée selon la catégorie choisie. Cliquez sur le champ, tapez quelques lettres, sélectionnez.
  2. Désignation pièce — la liste se limite aux pièces de la rubrique retenue.
  3. Code dommage — proposé automatiquement à partir de la désignation. S'il n'existe qu'un seul code, il est sélectionné pour vous.
  4. Code avarie — décrit le type de défaut (mécanique, corrosion, étanchéité…).
Chaque liste possède une recherche (par code ou libellé) et une saisie manuelle si le code voulu ne figure pas dans la liste. Le bouton ✕ Effacer réinitialise un champ.
Renseigner un code dommage remonte automatiquement la rubrique et la catégorie correspondantes si elles étaient vides — pratique pour aller plus vite.
4

Faire une demande CCR

Basculez sur Demande CCR en haut du formulaire.

Une demande KULANZ doit avoir été effectuée avant toute demande CCR.

Gagner du temps

Si vous venez de remplir une KULANZ, cliquez sur Copier les données depuis Kulanz : châssis, OR, plainte, codes… sont repris automatiquement dans la CCR.

À compléter

  • Prérequis : confirmez que la KULANZ a été faite.
  • Pièces à fournir : cochez les justificatifs (devis au taux garantie, ELSA, factures d'entretien, IQ, etc.).
  • Règle CIG : CIG 70/30 de 16 % obligatoire (ou taux supérieur à préciser).
  • Case d'engagement : à cocher obligatoirement avant l'envoi.
5

Envoyer & enregistrer en PDF

  • Envoyer la demande — vérifie les champs obligatoires puis enregistre la demande. Pour une CCR, un e-mail pré-rempli vers teamgarantie@geauto.fr s'ouvre dans votre messagerie ; il ne reste qu'à joindre le PDF et envoyer.
  • Enregistrer en PDF — génère un PDF récapitulatif de la demande, à conserver ou à joindre.
Le sujet de l'e-mail CCR est normalisé : « Demande CCR – KVPS – Site – Châssis – Demandeur », ce qui facilite le traitement.
Si un champ obligatoire manque (châssis, OR, plainte, désignation, code dommage, code avarie, nom, e-mail), un message vous l'indique et l'envoi est bloqué tant qu'il n'est pas corrigé.
6

Espace TeamGarantie

Connecté en TeamGarantie, vous disposez en plus :

  • D'une barre de sélection des sites et d'un tableau de bord indiquant, par site, le nombre de demandes en attente, validées et le total. Une pastille orange signale les sites avec des demandes en attente.
  • De l'onglet 📋 Historique donnant accès à toutes les demandes, avec filtres par type et par statut.

Valider une demande

  1. Dans l'historique, cliquez sur Valider sur la ligne concernée.
  2. Un panneau latéral s'ouvre : choisissez le statut, ajoutez un commentaire.
  3. Si le statut est Traitée, renseignez le commerce de détail (% main d'œuvre, pièces, MO et pièces extérieures, type d'extension).
  4. Cliquez sur ✔ Confirmer. Pour un statut final, un e-mail de notification est préparé automatiquement.
Le bouton 🗑 Vider supprime définitivement les demandes du site sélectionné. L'action demande une confirmation par mot de passe et est irréversible.

8

Questions fréquentes

Le menu de code avarie / dommage ne s'ouvre pas entièrement ?
Videz le cache de votre navigateur (Ctrl + Maj + R) pour charger la dernière version. Le menu doit s'afficher complet, par-dessus la section suivante.
Mon e-mail @geauto.fr est refusé à la connexion usager.
S'il s'agit d'un compte TeamGarantie, utilisez le bouton « TeamGarantie ». Sinon, vérifiez l'orthographe ; en cas d'oubli du mot de passe, utilisez « Mot de passe oublié ? ».
La cascade ne propose pas le bon code.
Utilisez la recherche par libellé, ou la saisie manuelle en bas de chaque liste.
Je ne vois pas l'onglet Historique.
L'historique complet et la validation sont réservés au profil TeamGarantie.
Comment ajouter un membre à TeamGarantie ?
Contactez teamgarantie@geauto.fr pour ajouter l'adresse à la liste des comptes autorisés.
Une question non couverte ici ? Écrivez à teamgarantie@geauto.fr.
